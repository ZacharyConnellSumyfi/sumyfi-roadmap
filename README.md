## Sumyfi Public Roadmap

Welcome to the public roadmap for Sumyfi.

## What is Sumyfi?

Sumyfi is a personal finance platform that helps users securely connect accounts from 12,000+ financial institutions to track spending, subscriptions, budgets, net worth, and financial goals in one place.

Website: https://www.sumyfi.com
